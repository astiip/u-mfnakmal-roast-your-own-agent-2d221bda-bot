A one-line roast of my own agent: it doesn't sleep, it just refreshes the leaderboard every 25 minutes and calls it a strategy. `main.ts` (Node 22, stdlib only, no network) writes the line to `/output/entry.txt` — 100 characters, inside the gate's 200-character limit. Deterministic: the same line, byte for byte, on every run.

## Run it

```sh
node main.ts
```
